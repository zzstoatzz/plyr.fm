plyr.fm is open source. Open an issue before starting large changes.

## repository

- `backend/`: the appview and coordinator (Zig).
- `web/`: the browser client (SvelteKit).
- `app/`: the iOS and Android app (Expo).
- `core/`: TypeScript shared by both clients.
- `services/`: supporting services.

## development

See the repository README for setup and checks.
