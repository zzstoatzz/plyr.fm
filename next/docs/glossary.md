---
title: "glossary"
description: "terms used in plyr.fm and the AT Protocol"
---

**AppView**: a service that indexes records from the network and serves them.
plyr.fm is an AppView for audio.

**PDS**: the server that hosts an account's repository.

**record**: a typed JSON object in a repository, such as a track or a like.

**lexicon**: a schema for a record type or an API method.

**NSID**: the reverse-DNS name of a lexicon, such as `fm.plyr.track`.

**XRPC**: the HTTP convention atproto uses for API methods.

**space**: a permissioned set of records, used for closed releases and jams.

**label**: a moderation tag a labeler attaches to a record or account.
